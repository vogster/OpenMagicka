# OpenMagicka — бэклог

Бэклог ведётся в ChillaDesk, проект **OM** (59 задач, связи-блокировки между ними).
Документация из `docs/` зеркалируется в вики проекта командой:

```bash
python tools/wiki_sync.py
```

## Вехи

| Веха | Суть | Критический путь |
|---|---|---|
| M0 Основа проекта | лицензия, каркас .NET 10 + FNA, лаунчер, VFS без регистра, legacy-хэш строк | OM-2 → OM-5, OM-6 |
| M1 Контент-пайплайн | LZX, XNB v4, все reader'ы, XML-парсеры, проверка XACT | OM-8 → OM-9 → OM-10 → OM-12 → OM-13 |
| M2 Рендер | потоки, оригинальные шейдеры через MojoShader, deferred, частицы | OM-19 → OM-20 → OM-22 → OM-23 |
| M3 Игровое ядро | физика, сущности, заклинания, урон, магики, AI, навмеш | OM-34 → OM-35 → OM-36 |
| M4 Уровни и скрипты | триггеры, 24 условия, 113 действий, чекпоинты | OM-43 → OM-45 → OM-47 → OM-50 (глава 1) |
| M5 UI, звук, сохранения | аудио, локализация, меню, HUD, импорт сейвов | |
| M6 Мультиплеер | локальный кооп, свой сетевой протокол | |

Главные риски: совместимость XACT v45/xWMA с FAudio (OM-18), запуск fx_2_0 через FNA (OM-20),
лицензия JigLibX (OM-7).
